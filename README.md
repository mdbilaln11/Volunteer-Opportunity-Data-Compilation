# 🌍 Volunteer Opportunity Data Compilation – India

### InAmigos Foundation | Data Analytics Internship 

## 📌 Project Overview

This project focuses on researching, collecting, and organizing information about volunteer opportunities, internships, fellowships, and social initiatives available for students across India.

The objective is to create a structured database that helps students discover opportunities to gain practical experience, develop professional skills, and contribute to society.

## 🎯 Objectives

- Research volunteer opportunities across India.
- Identify internships and fellowships offered by different organizations.
- Collect eligibility criteria and application deadlines.
- Gather official application links.
- Organize the collected information into a structured Excel database.
- Develop research, data collection, and data organization skills.
